# Pages

There are no screenshots yet: the app was built and unit-tested on a non-Windows CI machine, so it hasn't been run on Windows. This file describes each page instead. Screenshots can replace it once it has run on Windows.

**Layout.** A frameless dark window. The custom title bar holds the logo, a global search box (Ctrl+F) and minimise, maximise and close buttons. On Windows 11 the window has rounded corners. A 232 px sidebar has icon and label navigation, plus a "This PC" summary card at the bottom. One neon accent colour (violet by default, changeable in Settings) is used for selection, toggles, glows and graphs. When something is pending, a floating **pending changes bar** at the bottom shows a counter badge, **Discard** and a glowing **Apply** button. Toasts slide in at the bottom right. A restart banner appears above the content when a change needs a restart, sign-out or Explorer restart.

| Page | What you see |
|---|---|
| **Dashboard** | Four live cards (CPU, GPU, Memory, Disk) with the current % and a 60-second sparkline. A **System health** ring (0–100) with every factor listed beside it: free space, memory pressure, startup apps, recommended tweaks applied, junk, pending restart. An OS card. A **Recommended for this PC** list with toggles. A big **Optimize** button that selects the Balanced preset plus everything recommended for your hardware, then opens the confirmation dialog. |
| **Quick Optimize** | Five preset cards (Gaming, Balanced, Low-End PC, Privacy, Max Performance), each showing how many tweaks it selects on this PC and their names. **Select** pre-toggles them. Below is the live list of pending changes as tweak cards. |
| **Gaming, Performance, Network, Privacy, Debloat, Services, Input, Power, Visuals, Advanced** | A preset chip row (Gaming / Balanced / Low-End PC / Privacy / Max Performance / Custom) above a grid of tweak cards. Each card has a title, a description, an animated toggle, a risk badge (green Safe, amber Moderate, red Advanced), a restart pill, "For your PC" and "Pending" pills, a status line ("Applied by frtune", "Already set on this PC"…), and a **Details ⓘ** tooltip listing every registry value, service, task or command. Cards glow in the accent colour on hover. Tweaks that don't apply are hidden, and a checkbox reveals them greyed out with the reason. |
| Gaming (extra) | **Per-game settings**: add a game `.exe`, choose GPU preference and CPU priority. Both are stored where Windows reads them (UserGpuPreferences and Image File Execution Options), so they apply on every launch. |
| Network (extra) | **DNS switcher**: current DNS per adapter; Cloudflare, Google, Quad9 and AdGuard cards with **Use**; a **Test latency** button (median of 4 pings, fastest highlighted); custom servers; **Restore original DNS**. Repair buttons: Flush DNS, Reset Winsock, Reset TCP/IP. |
| Debloat (extra) | A three-column checklist of installed Store apps. Suggested removals are pre-ticked, protected apps (Store, Calculator, Photos, Terminal, codecs, GPU control panels…) are locked. **Remove selected** lists everything before removing. A separate **Uninstall OneDrive** card has a data warning. |
| Services (extra) | Preset service tweaks as cards. **Show all services** expands a searchable, virtualised list: name, plain-language advice ("Safe to disable", "Keep: firewall"…), state, an Auto/Delayed/Manual/Off segmented control, and **Undo**, which restores the original saved the first time you changed it. Essential and security services can't be disabled. |
| Power (extra) | Every power plan with an **Activate** button, and a creator that duplicates Balanced, High performance or Ultimate under your own name and activates it. |
| **Startup** | Every startup entry from the Run keys (user, machine, 32-bit), both Startup folders, and logon scheduled tasks, with publisher, source, estimated impact (High/Medium/Low) and a toggle. Toggles use Task Manager's own StartupApproved flags. |
| **Cleaner** | Two columns of categories (temp, thumbnails, DirectX/NVIDIA/AMD shader caches, Chrome/Edge/Brave/Firefox caches, crash dumps, logs, prefetch, Recycle Bin, Windows Update cache, Windows.old), each with a risk badge and its measured size. A **Clean X GB** button with a progress bar. A weekly auto-clean toggle (Task Scheduler). Large-file and duplicate finders, which only move a file to the Recycle Bin when you click **Recycle**. |
| **Backups & Restore** | **Restore everything**, **Create restore point now**, **Open System Restore**, open the backup folder or change log. A list of every applied tweak with when it was applied, how many values were saved, and a **Revert** button. The full change log, newest first, with success or failure icons and details on hover. |
| **Hardware** (Extras) | A mini CPU-Z. Processor (cores, clocks, cache, socket), graphics (VRAM read from the driver key, so it isn't capped at 4 GB), each memory stick (size, speed, part number), disks (SSD/HDD, NVMe/SATA), motherboard, BIOS and OS. Plus "Notes for this PC", such as single-channel RAM or the CPU having no iGPU. |
| **Benchmark** (Extras) | A labelled ~10 s CPU (single and multi-thread SHA-256), memory bandwidth and 256 MB disk test. The last two runs are compared side by side with % change, and the history is kept. |
| **Processes** (Extras) | Processes sorted by memory, with checkboxes (Windows and security processes are locked), a "Boost" picker and **Kill & boost**, which ends the ticked apps and sets the chosen game to High priority. |
| **Settings** (Extras) | Accent swatches plus a custom hex value (applies instantly), restore-point and raw-export toggles, Windows Update pause days, profile export/import, the detected-system summary, the data folder, and the privacy statement. |
| **Confirmation dialog** | Lists every tweak with Apply/Revert, its risk, and the exact lines it will write. Warnings show in red. Tweaks that will be skipped (for example "no backup exists") are dimmed with the reason. If any Advanced item is included, the Apply button stays disabled until you tick "I understand". |
